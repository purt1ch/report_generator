## Введение
* Программа генерирует готовые документы .docx (доклады, сообщения, рефераты) на всевозможные темы при помощи API Google Gemini.
* Программа реализована на платформе *NodeJs* и поэтому требует изначальной установки Node для запуска.
* Для Linux-систем:

    ```sh
    pkg install nodejs
    ```

# Структура
| Файл | Назначение |
| --- | --- |
| `main.js` | Точка входа: подстановка данных в шаблон и сборка .docx |
| `gpt.js` | Запрос к Gemini через OpenAI-совместимый API |
| `request.js` | Список тем, преподавателей и номеров курсантов |
| `data.json` | Списки преподавателей и курсантов |
| `assets/input.docx` | Шаблон .docx с плейсхолдерами |
| `outputdocs/` | Папка с готовыми документами |
| `DocGenPC.bat` | Запуск на Windows |

## Важно
* В связи с тем, что Google заблокировала доступ к API Gemini из России, для работы программы требуется *прокси* или *VPN* подключение. Свой адрес API указывается в `.env` (переменная `GEMINI_BASE_URL`).
* В файле data.json размещён список преподавателей и курсантов для удобства записи нескольких запросов в `request.js`. В репозитории лежат обезличенные (вымышленные) данные — замените их своими.
* Название учебной организации, группа, город и год задаются в объекте `settings` в начале файла `main.js`.
* Файл `.env` с ключами API находится в `.gitignore` и не должен попадать в репозиторий. В качестве образца используйте `.env.example`.

# Установка
* Чтобы воспользоваться программой, следуйте указанным ниже шагам:
## Для начала:

1. **Скопируйте репозиторий**: Скачайте код программы с Гитхаба:
    ```sh
        git clone https://github.com/purt1ch/report_generator.git
    ```
2. **Перейдите в папку с кодом**:
    ```sh
        cd report_generator
    ```


3. **Установите зависимости**: Установите библиотеки, нужные для работы скрипта через `package.json`, используя `npm`.
    ```sh
         npm install
    ```
4. **Создайте файл `.env`**: скопируйте `.env.example` в `.env` и подставьте свои ключи и адрес API.

5. **Настройте параметры документа**: откройте `data.json` и внесите преподавателей и курсантов, затем заполните `request.js`. Титульные данные (`institution`, `group`, `city`, `year`) задаются в `settings` в начале `main.js`.

6. **Запустите скрипт**:
    ```sh
        node main.js
    ```
    или через `npm start`.
* Для удобства запуска с платформы Windows присутствует shell-скрипт *DocGenPC.bat*

### Итоговые документы сохраняются в папку `./outputdocs`
Пример готового документа — `outputdocs/example.docx`
